Native Rust desktop edition with the Black Knight grayscale palette, an interactive 18-topic prerequisite roadmap, and 16 data structure labs.

Each roadmap topic and each structure has ten computed worked cases (3 easy, 4 medium, 3 hard). Cases include variations on a core method; they are not 340 unrelated interview problems. Lessons cover motivation, operation, use cases, industry examples and historical context with references. Python remains optional reference text.

Download one executable matching your OS and CPU. No browser or Rust/Python installation is needed to run it. There are separate Linux x86_64, Windows x86_64, macOS Apple Silicon and macOS Intel assets; there is no universal cross-OS executable. Linux requires a normal graphical desktop, OpenGL/xkbcommon and glibc 2.35+. Executables are unsigned/not Apple-notarized. SHA256SUMS.txt lists asset checksums.

Playback is bounded and repainting is event-driven. Structure frames show complete operations; algorithm frames expose selected internal steps. This version does not implement every specialized data structure or every algorithm within a roadmap category. See README for exact coverage and model limitations.
